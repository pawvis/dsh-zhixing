# 知行 · 功能说明

所有数据在本机 `$DSH_HOME/data/知行/`（默认 `~/.dsh/data/知行/`），所有工作区共用。

## 今日

- **待办事项**：一个列表，按到期时间分成「此前未完成」「今日待办」「之后（按日期）」；
  跨天未完成的可以「顺延」或「关闭」。
- **新增 / 编辑待办**：都用弹窗卡片；截止日期支持日期 + 时分，关联目标可模糊搜索、下拉里可直接「＋ 新增目标」，
  弹窗里可以直接「＋ 新增目标」（再叠一个目标弹窗），也可以输入一段话让 AI 拆成多条待办。
- **批量删除**：待办卡「批量删除」进入选择模式，可全选、删除选中（二次确认）。
  昨天的日报会把「明天准备干什么」写成今天的待办。
- **加入搭子待办**：选中聊天文字会出现浮动按钮，右键选区/我的消息有菜单项，
  AI 回答下方也有「加入待办」。点了直接存：取第一句、去非法字符、截 40 字，
  重名自动加 `-2`；失败会弹错误提示。
- 今日页 = 左侧待办 + 右侧日历，中间分隔条可拖宽；上方横幅按「天气 → 时间 → 每日一句」左对齐排列。
- 右侧日历是内容日历样式：每格显示日期和当天日报标题小条，支持年月翻页；有日报点开查看/编辑，没有就新建。
- 日历下面是「AI 助手」：支持一段话、URL 链接、附件（文档会解析正文；图片/视频会接收但不做内容识别），点「一键生成待办」直接加到今日。
- 「生成日报」不再常驻页面，改为日历里点日期或「新建今天日报」打开的弹窗。
- 待办支持「列表 / 甘特」视图，甘特按起止日期画圆角条、状态点、虚线今天标记和日期轴。
- 天气按设置里的地区显示，可在设置里改城市或关闭；时间支持 24/12 小时制与是否显示秒。每日一句内置 100 条按天轮换，也可自定义。
- **时区跟随地区**：设置里选的城市决定整个插件的时区。首页时钟与日期、「今天」相关日期、待办/日报日期、提醒时间、今天吃什么、今日运势和 AI 提示里的日期都按该城市当地时间计算，设置页会同时显示该城市的时区与当前日期时间。
- 待办分组（此前未完成 / 今日 / 之后）点击标题可折叠。
- **生成日报（分步）**：
  1. 点「从 Harness 会话采集」，得到一份可编辑的采集草稿；
  2. 在草稿里继续补充、修改；
  3. 上传附件（md/txt/docx/doc/xlsx/xls/pptx/ppt，原始文件落到 `导入/<日期>/`）；
  4. 点「生成日报」得到草稿，可编辑，确认保存才写文件并生成次日待办。
- **今天的日报**：保存后直接在同一张卡片里就地编辑（不再弹到下面），
  并自动带上「关联目标」标签；标签可删除、可手动增补。
- **AI 进度建议**：保存日报后后台分析，命中的目标会出现建议卡片，点「采纳」才改进度。
- **AI 批量更新进度**：目标页「AI 更新进度」一次性评估所有叶子目标；弹窗内先「开始评估」，确认后「一键更新选中」才写入，单次最多 +30%，已完成目标自动跳过。

## 日报

- 进入页面默认打开**最近一份**；「列表」按生成时间倒序，支持「按时间 / 按分组」切换。
- 每条左边有「日报 / 周报 / 月报」标签；周报月报与日报一样可编辑、复制、导出、删除。
- 「日报列表」和右侧详情之间可以**拖动分隔条**调整宽度（记住上次宽度）。
- 历史日报**支持直接编辑保存**；文件是纯 Markdown，Obsidian 也可编辑。
- 工具栏：编辑、一键复制、**导出 ▾**（PDF / PNG / HTML）、模板、HTML 预览、删除（二次确认）；HTML 预览会铺满日报详情区，长日报在预览框内滚动。
- 关联目标 tag 会带上周期（年/季度/月/周），出现在详情、列表以及导出/预览的 HTML 里；关联目标弹窗支持模糊搜索，也可以直接「＋ 新建目标」，保存后自动勾选。
- 「建议再关联 N 个目标」在详情里展开成内嵌面板（不再用悬浮层遮住正文）；面板里有「关联目标分析」（列出每个目标命中的关键词、依据原句和把握度）、「忽略全部」（一次忽略全部建议）和「一键全部关联」，关联后 6 秒内可撤销。
- 列表头部「＋」下拉：生成周报 / 生成月报；AI 生成后可编辑、导出（PDF/图片/HTML）、删除，并自动继承该周期日报的关联目标。

## 目标

- 新建周 / 月 / 季度 / 年目标，可挂上级：年度 → 季度 → 月度 → 周，任意深度；上级目标下拉里可以直接「＋ 新建上级目标」。
- 每条必须填衡量方式，例如「完成 3 份标准文档」。
- 年度目标在列表视图里两列并排，季度/月/周目标单列。
- 上级目标只能选更高层级（年 > 季度 > 月 > 周），新建/编辑弹窗会过滤，宿主也会校验；导入保存时同级/非法上级会落成顶层。
- 新建目标弹窗里可以直接粘贴文字或上传文件让 AI 拆解，再填入表单或全部导入。
- 时间轴的目标标题前用彩色徽标标出年/季度/月/周；列表按飞书 OKR 风格：目标一行展示进度百分比和进度条，子目标按层级递归缩进（彩色周期徽标 + 虚线连接线）；
  新建 / 编辑都在弹窗里完成，删除有二次确认。
- 支持「列表 / 时间轴」两种视图：时间轴按起止日期画进度条，并标出今天。
- 有子目标时进度默认由子目标平均值自动重算；手动改过（`manual: true`）的以手动值为准，叶子目标可手改或采纳 AI 建议。
- 删除上级会解除子目标关联（不删子目标），也可以在确认框里选「一起删除」把所有下级目标一起删掉；两种删除都支持 6 秒内撤销。
- 导入：粘贴文本或上传文档，AI 分块拆解（每 6000 字一段，最多 8 段），
  给出标题 / 详细说明 / 周期 / 起止 / 衡量方式 / 层级，按 年 → 季度 → 月 → 周 拼成树；预览里可逐条改（改周期会同步重算起止日期）、删、临时收起，确认后才写入 `目标.json`。
- 标题只放简短结果（20 字以内），具体范围、做法和交付物放在每条目标下面新增的「详细说明」里；模型仍给出过长标题时，会再调一次 AI 批量缩写，缩写失败就保持原样，不影响导入。
- 模型输出被 `maxTokens` 截断或夹带脏格式时，会尽量补全/回收完整目标；只救回部分时界面会提示「输出被截断」。
  彻底失败时模型原文写到 `.internal/last-ai-raw.txt`，方便排查。
- 解析失败会明确指出「哪个文件、什么原因」（例如不是 OLE 复合文档、缺少 LibreOffice）。

## 提醒

- 工作日 `09:00`：「今天的待办有 N 项：…，请及时完成哦。」（可改时间）
- 工作日 `18:00`：提醒写日报；当天已有日报就不提醒。
- 目标连续 N 天没更新（默认 3 天）：「目标「xxx」已经 3 天没有更新了，这个进度你要关注一下。」
- 时间已过 80% 而进度低于 60%：目标风险提醒。
- 同一目标同类提醒每天最多 1 次；默认跳过周末，可维护节假日 / 调休表。
- 页面可见走 Web Notification；点击通知会聚焦并切到「今日」，同时弹出提醒卡片：
  5 秒倒计时自动消失，也可以点「关闭」。页面隐藏、最小化或没打开时走 macOS 系统通知。
- 定时器只在 dsh 进程存活时运行；错过的提醒启动后补发一次，同日去重。

## 日报模板

- 默认模板是自带的一份 A4 风格 HTML，含 `{{title}}` `{{date}}` `{{content}}` `{{tags}}` `{{generatedAt}}` 占位符；
  模板没写 `{{tags}}` 时，关联目标会自动插在正文前面。
- 模板可：在弹窗里直接改、上传本地 `.html`、恢复默认、用一句话让 AI 修改
  （AI 只返回预览，确认保存才生效）。`{{content}}` 必填。
- 模板文件：`$DSH_HOME/data/知行/模板/日报.html`。

## 模型

- 右上角模型下拉：列出 DSH 里配置的全部模型，按渠道（provider）分组，每组可折叠，
  顶部输入框支持模糊搜索（包含匹配或字母顺序子序列）；选中后插件只用自己的这条选择，
  选「跟随 Harness」则实时读当前会话模型，其次默认模型。
- `log.md` 记录每次调用实际使用的 `provider/model/reasoningEffort` 与来源。
- 不带 Key、不改宿主配置；不限调用次数（设置里已去掉 AI 开关）；失败重试 2 次。

## 主题

- 浅色：`#F7F7F5` / 卡片 `#FFFFFF` / 正文 `#1F1F1F` / 强调 `#3B82F6`
- 暗色：`#141414` / `#1E1E1E` / `#EDEDED` / `#60A5FA`
- 四种切换方式：跟随 DSH（自动）、固定浅色、固定暗色、按时间（默认 07:00–19:00 浅色）。
- 样式全部写在插件根容器 `.wb-root` 下，不改宿主 token；切换只更新根节点属性，整页立即生效。

## 数据

```text
$DSH_HOME/data/知行/
├── 日报/YYYY-MM-DD.md
├── 待办.json                # id、内容、日期、来源日报、状态、关联目标
├── 目标.json                # 标题、详细说明、周期、起止、上级、衡量方式、进度、记录
├── 导入/<日期>/             # 原始文件，只读
├── 模板/日报.html           # 自定义 HTML 模板
├── 语录/语录.json           # 自定义每日一句
├── 汇总/YYYY-Www.md         # 周报 / 月报
├── log.md                   # 时间 | 动作 | 结果
├── 待办与目标总览.md        # 每次改 json 后重写的只读镜像
├── settings.json            # 提醒时间、节假日、模型选择、主题、隐私开关
├── state.json               # 提醒去重、AI 计数、页面心跳
├── 北极星/北极星.md          # 2.0 反愿景 / 愿景 / 身份宣言 / 规则（人生面）
├── 北极星/身份证据.md        # 2.0 身份证据（人生面）
├── 偏航/YYYY-Www.md          # 2.0 偏航报告（人生面）
├── .internal/levers.json     # 2.0 今日杠杆
├── .internal/drift.json      # 2.0 偏航统计快照
├── .internal/metrics.json    # 2.0 本地使用统计（只有数字）
└── .internal/               # 采集缓存与待确认建议（可删）
```

`待办.json` / `目标.json` 用「临时文件 + rename」并加写锁，页面与定时任务不会互相覆盖。

## 测试触发（不改系统时间）

设置页有按钮，也可以直接请求：

```text
POST /api/zhixing/debug/morning       模拟 9:00 早安提醒（可带 date / at / channel）
POST /api/zhixing/debug/evening       模拟 18:00 日报提醒
POST /api/zhixing/debug/goal-check    检查目标停滞 / 风险提醒
POST /api/zhixing/debug/goal-age      把目标更新时间改到 N 天前（{id, days}）
POST /api/zhixing/debug/seed          生成性能测试数据（{goals,todos,reports}）
POST /api/zhixing/debug/seed/clear    清理性能测试数据
POST /api/zhixing/debug/model         切换会话 / 插件 / 默认模型
GET  /api/zhixing/debug/state         提醒去重、AI 次数、心跳、通知渠道
```

这些接口默认不注册，需要给 DSH 进程设置环境变量 `ZHIXING_DEBUG=1` 后才可用；关闭时统一返回 404，设置页的「调试」卡片也会隐藏。

测试记录会以 `[测试]` 写进 `log.md`。

## 卸载

在 Plugins 里移除本插件即可；数据目录不会自动删除，需要时手动删掉
`$DSH_HOME/data/知行/`。

## 已知限制

- 会话采集只扫「今天创建 / 当前活跃 / 最近 7 天创建」的会话。
- 关掉 dsh 期间不会发提醒，只能启动后补发。
- 系统通知依赖 macOS 通知权限；首次可能需要在系统设置里允许。
- 旧版 `.xls/.ppt` 拆目标的质量取决于文件内容与内置 LibreOffice 转换结果；
  没有 LibreOffice 时会按文件报错，不会静默跳过。
- 「目标风险」以自然日计算（时间过 80% 且进度 < 60%）。
- 「转发飞书 / 微信」没有官方机器人接入：优先调系统分享面板，不支持时复制富文本，
  需要你切到对应应用粘贴；不会代替你发送。
- 导出图片用浏览器把 HTML 模板栅格化为 PNG；自定义模板若引用外部图片/远程字体，
  图片里可能缺失（本地资源请内联为 data URL）。
